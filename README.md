## ✨ 주요 기능

- **대표작 · 논문 반영 애플리케이션 (MediMatch)**:
  - 병원정보시스템(HIS) 5단계 다차원 교차검증 및 정부24 안심상속 공공연계 실시간 시뮬레이터 탑재
  - 대학병원 5,000건 대규모 모의 데이터셋 및 150건 원자료 기반 4대 핵심 가설 실증 검정(식별률 84.0% 달성, 소요일수 9.6일로 단축, 적격확인율 80.0%, 중위잔류기간 7일)
  - 트랜잭션별 전자 직인 및 SHA-256 감사 무결성 해시 발급
- **학술 연구 논문 전문 뷰어**:
  - 병원경영학회지 규격 논문 전문 인앱 모달 뷰어(초록, 서론, 이론적 고찰, 연구 방법, 연구 결과, 결론, 참고문헌) 탑재
  - 고해상도 실증 통계 차트 4종 및 실증 요약표 포함, 장별 빠른 이동 내비게이션 지원
- **다크/라이트 모드**: CSS Custom Properties 기반 부드러운 테마 전환 (해 ↔ 달 모핑 애니메이션)
- **타임라인**: 병원 행정에서 보안 엔지니어로의 전환 과정을 시각화, 진행 중인 구간에 동적 점선 애니메이션 적용
- **SAR 강점 섹션**: 아코디언 형태로 상황(Situation)-행동(Action)-결과(Result) 구조의 핵심 강점 펼쳐보기
- **서사 문서 & 수료증 모달**: 나를 말하는 서사 및 자격/수료 내역 확인 (ESC 키, 오버레이 클릭, 포커스 트랩 지원)
- **반응형 디자인 & 가독성 최적화**: 모바일/태블릿/데스크톱 대응 및 텍스트 대비, 여백 균형 최적화
