## ✨ 주요 기능

- **다크/라이트 모드**: CSS 트랜지션 기반 부드러운 테마 전환 (해 ↔ 달 모핑 애니메이션)
- **학술 연구 논문 섹션 & 뷰어**: 병원정보시스템(HIS) 및 공공행정정보 연계 연구 논문 전문 뷰어 탑재
- **타임라인**: 경력 전환 과정을 시각화, 진행 중인 구간에 동적 점선 애니메이션 적용
- **SAR 강점 섹션**: 아코디언 형태로 상황-행동-결과 구조의 핵심 강점 펼쳐보기
- **서사 문서 & 수료증 모달**: 나를 말하는 서사 및 자격/수료 내역 확인 (ESC 키, 오버레이 클릭 지원)
- **반응형 디자인 & 접근성**: 데스크톱 / 태블릿 / 모바일 대응, 시맨틱 HTML 적용
