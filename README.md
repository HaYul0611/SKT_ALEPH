**[https://hayul0611.github.io/SKT_ALEPH/](https://hayul0611.github.io/SKT_ALEPH/)**

## 📌 소개

병원 행정 중간관리자 출신으로, 웹 풀스택 과정을 이수하고 현재 **SKT ALEPH 인프라/보안 과정**을 수강하며 보안 엔지니어로의 전환을 준비하고 있습니다.

## 🛠 기술 스택

| 구분 | 기술 |
|------|------|
| Frontend | HTML, CSS, JavaScript |
| 폰트 | Noto Sans KR (Google Fonts) |
| 배포 | GitHub Pages |

## 📂 프로젝트 구조

```
SKT_ALEPH/
```

## ✨ 주요 기능

- **다크/라이트 모드**: CSS 트랜지션 기반 부드러운 테마 전환 (해 ↔ 달 모핑 애니메이션)
- **타임라인**: 경력 전환 과정을 시각화, 진행 중인 구간에 동적 점선 애니메이션 적용
- **SAR 강점 섹션**: 아코디언 형태로 상황-행동-결과 구조의 핵심 강점 펼쳐보기
- **수료증 모달**: 웹풀스택 과정 수료증 확인 (ESC 키, 오버레이 클릭으로 닫기)
- **반응형 디자인**: 데스크톱 / 태블릿 / 모바일 대응
- **접근성**: ARIA 속성, 키보드 내비게이션, 시맨틱 HTML 적용
